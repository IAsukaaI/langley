PRIVACY POLICY & DATA HANDLING 

================================================================================
                             P R I V A C Y   P O L I C Y
================================================================================

Effective Date: November 17, 2026
Application: Lang!ley (Desktop & Microsoft Store Edition)
Developer: Asukaa (https://asukaa.de)

1. ZERO PERSONAL DATA COLLECTION & NO TELEMETRY
Lang!ley operates strictly as a local-first desktop utility. We do not collect, 
track, store, transmit, or sell any personal data, usage analytics, crash 
reports, or telemetry to any external servers.

2. LOCAL PROCESS & GAME STATE DETECTION
To display your active game status on Discord, Lang!ley checks running game 
processes, window titles, and local game logs/configuration files strictly in 
local memory on your device. This information never leaves your computer except 
to update your own local Discord client.

3. LOCAL CONFIGURATION STORAGE
All user preferences, custom settings, and cached game icons are stored locally 
on your machine inside your Windows user directory (%APPDATA%\Lang!ley). Removing 
this folder or uninstalling the application deletes your local configuration.

4. DISCORD RICH PRESENCE INTEGRATION
Lang!ley communicates exclusively with the local Discord desktop client running 
on your PC via Discord's standard local Inter-Process Communication (IPC) pipe. 
Any status displayed on your Discord profile is governed by Discord's own 
Privacy Policy and your personal Discord Activity Privacy settings.

5. UPDATES
- Microsoft Store Edition: Updates are handled entirely by the Microsoft Store.
- Standalone Installer Edition: Checks https://asukaa.de/langley/ solely to 
  compare the current version number against the latest release.

6. CONTACT
If you have any questions regarding this Privacy Policy, please reach out via 
https://asukaa.de.
