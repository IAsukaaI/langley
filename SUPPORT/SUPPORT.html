COMMON TROUBLESHOOTING GUIDE

1. My Discord Rich Presence is not showing up ▼
  • • Make sure the Discord Desktop App is running on your PC (Discord in a web browser cannot receive local RPC connections).
  • • In Discord, go to User Settings → Activity Privacy and enable "Share your detected activity with others".
  • • Enable Discord Priority Guard inside Lang!ley if background apps like Medal.tv overwrite your status.
2. A game is running, but Lang!ley doesn't show it ▼
  • • Check that the game is not minimized to the taskbar (Lang!ley ignores minimized games and background launchers by design).
  • • Verify in Lang!ley's Settings that detection for that platform or game is toggled ON.
3. Where are my settings stored / How do I reset Lang!ley? ▼

All configurations and cached assets are stored locally in %APPDATA%\Lang!ley (press Win + R, paste %APPDATA%\Lang!ley, and hit Enter). Deleting this folder while Lang!ley is closed resets all settings to factory defaults.

4. How do updates work (Microsoft Store vs. Standalone)? ▼

• Microsoft Store Edition: Updates automatically through the Microsoft Store app.
• Standalone Edition: Uses the built-in updater on launch or can be downloaded from GitHub Releases.
